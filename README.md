# Aerofind

**Aerofind** is an E-Commerce mobile application built using **Flutter**, with a backend powered by **FastAPI** and **Supabase**.

---

**Tech Stack**  
Flutter — Frontend framework for cross-platform mobile development  
FastAPI — High-performance Python backend for REST APIs  
Supabase — Backend-as-a-service for database, authentication, and storage

---

## Getting Started

Follow these steps to clone and run the Flutter app locally.

```bash
# Clone the Repository
git clone https://github.com/bearface4/Aerofind.git
cd aerofind-mobile-app

# Install Dependencies
# Make sure you have Flutter installed on your system.
flutter pub get

# Run the App
# Connect your device or start an emulator, then run:
flutter run
```
